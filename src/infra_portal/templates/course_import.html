The course is written as notes in the notes repository. That repository is private and this one is public, so the notes are not kept here as files. Upload them and they are stored as drafts.

What is read

  • A stage note, titled like "..., stage 2: Bread". Each ## Chunk N. Title section becomes a chunk. Each ### Build N. Title heading names a build. Nothing else in the note is stored.
  • A build note, titled "Stage 2, build 1: A first loaf". The whole note becomes that build.
  • A warm-up note, titled "Stage 2, chunk 3: warm-up". It is added to the end of chunk 3.
  • A table that starts with the columns Stage and Topic, in any note. Its rows name the stages.

What is never read

  • A file whose name ends in -mentor.md, or whose header says draft: true. Answer keys stay out.

Uploading again

  • A step that is already here gets the new text, title and place. Who sees it does not change, and neither do members' ticks.
  • A stage that is already here is left as it is.
